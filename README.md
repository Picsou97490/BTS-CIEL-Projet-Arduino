# Projet BTS CIEL – Arduino et réseaux informatiques

## Présentation du projet

Ce projet a été réalisé dans le cadre du BTS CIEL option B (Électronique et Réseaux).

L'objectif est de commander une LED à distance et de récupérer les mesures d'un capteur ultrason à partir d'une application Android et d'une interface Web.

## Matériel utilisé

- Arduino Mega 2560
- Module Bluetooth HC-05
- Capteur ultrason Grove
- LED et résistances
- Ordinateur et smartphone Android

## Logiciels utilisés

- Arduino IDE
- Python
- Flask
- PySerial
- MIT App Inventor
- Thonny

## Fonctionnalités

- Allumer et éteindre une LED à distance.
- Mesurer la distance d'un obstacle.
- Communiquer par Bluetooth.
- Superviser le système depuis une page Web.
- Transmettre des données par liaison série USB.
